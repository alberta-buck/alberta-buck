How to read these runs

Triangles mark actual swaps. Positive intent alone does not prove that a request cleared its allocation, minimum-size and execution constraints. The raw JSON records the book immediately before each response.

Basket net value is the BUCK value of the LP and idle inventory, plus held BUCK and accrued relief, minus issued BUCK liability. Compare it with the initial-investment line; the marked return includes bootstrap and live results and excludes liquidation costs and caller gas.

Enable “Keep settings linked across tests” to keep the policy comparisons on the same price selection. Turn it off for independent selections. Allocation axes fit the visible percentages.
