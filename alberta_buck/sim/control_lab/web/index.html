How to read and reproduce this experiment

Mixed adds triangular pulses, a lasting TOKEN C ramp, and independent Gaussian white noise with a standard deviation of 0.2% of each token’s baseline mean per observation. That white noise does not accumulate and is separate from the random-walk selector. A zero-mean random increment does not make an accumulated path average zero over these 120 days.

Drag the day-range controls to zoom; hover or focus a chart and use the arrow keys to inspect values across its panes. Click legend entries to hide or show lines. Shared vertical scales compare all stages and flow quantities for the selected profile and walk. To inspect tiny movements, disable shared scales and hide constant guide lines.

These are precomputed 120-day pyrevm experiments. Changing a selector loads an actual saved run; the browser does not approximate or interpolate a new experiment. A shared run is reused only when a control belongs to an actor absent from that stage.

The shock profile adds 30% of TOKEN A’s baseline mean to its external feed on days 45–55, before applying the random walk. This is an external repricing experiment. The separate one-pool disturbance experiment is planned in the design document. Historical EMAs exclude all live disturbances. Arbitrage profits remain with the arbitrage actor.
