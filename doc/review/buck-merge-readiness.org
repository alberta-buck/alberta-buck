* Target and current baseline

Merge =feature/household-minimal-ecosystem= into =master= when a visitor
can open the static Savings tab, run a small economy with autonomous
households, inspect what the agents are doing, and participate through
a simulated wallet. The Python simulator and JavaScript WebEVM world
must implement the same policies, market actions and accounting when run
with the same inputs. The browser may choose a smaller default population
and a different tick rate for responsiveness.

This plan is based on the main checkout at =e08a630b=. The canonical
basket is the current machine, with available-credit-first redemption
and near-zero idle cash. Use it for the prototype. The existing worker,
=LocalLink=, wallet and shared Savings page are the starting point. The
implementation history records passing Chromium tests for the static
Wallet and Savings tabs. Existing shared household fixtures cover parts of
policy and calendar behavior. Whole-economy parity and the full acceptance
suite on the merge candidate still require evidence.

Background and prior decisions are in the [[file:bucknet-economy-implementation.org][implementation plan]],
[[file:consolidation-plan.org][consolidation plan]] and [[file:buck-basket-findings.org][basket findings]].
