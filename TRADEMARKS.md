# Trademark and Naming Policy

**"Alberta Buck"** and **"BUCK"** as used for this project are unregistered
marks of Perry Kundert. This document says what you may and may not do with
the name. It is separate from, and not affected by, the source-code licences
described in `LICENSING.md`.

## Why this file exists at all

The code here is free software. The name is not part of that grant, and both
licences say so explicitly:

- **CAL-1.0 §3.1(b)** grants copyright and patent rights and expressly withholds
  trademark rights.
- **GPL-3.0 §7(e)** permits declining to grant rights in names and trademarks.

So the code and the name are on different footings by design, not by oversight.
The purpose of separating them is narrow: anyone may run, study, modify and
redistribute the software, and nobody may use the project's name to make their
version look like the original.

## What you may do

You do **not** need permission to:

- State truthfully that your work is **derived from**, **based on**,
  **compatible with**, or **interoperates with** Alberta Buck.
- Use the name to refer to this project in articles, papers, talks, reviews,
  comparisons, tutorials and documentation. This is nominative use and it is
  yours by right.
- Redistribute the software **unmodified**, under its own name, with its
  licences and notices intact.
- Use the name in the URL or title of a discussion, issue, fork on a code
  host, or academic citation.

## What requires a different name

Please choose a distinct name if you are:

- Naming a **fork**, a **modified distribution**, or a **competing
  implementation**.
- Naming a **deployed instance**, service, front-end, or hosted product built
  on this code.
- Naming a **token, coin, ticker symbol, or financial instrument**.
- Naming a company, product line, or domain in a way that suggests this
  project is its origin.

"Based on Alberta Buck" is fine. "Alberta Buck Pro", "AlbertaBuck.io", or a
token called ALBERTABUCK is not.

## What is not permitted

- Using the name or any confusingly similar variation in a way that implies
  **endorsement, affiliation, sponsorship, or official status** that does not
  exist.
- Using the name for a modified version in a way that would lead a reasonable
  person to believe they are getting the original.
- Registering the name, or a confusingly similar one, as a trademark, company
  name, domain, or package name in any registry.

## Modified versions

If you distribute a modified version, the licences already require you to mark
your changes. For the name, the request is simpler: **make it clear whose build
it is.** A name of your own plus an accurate "derived from Alberta Buck" line
satisfies everything in this document.

## Scope and honesty about it

This is an **unregistered** mark. Rights in an unregistered mark arise from use
in commerce and reach only the geography and market where reputation is
actually established; in Canada the relevant action is passing off, and in the
United States it is common-law trademark and unfair competition. "Alberta" is a
geographic term and "Buck" is descriptive of currency, which makes this a
**weak mark** — a fact stated here plainly rather than papered over.

This policy is therefore best read as a statement of the project's wishes and a
description of what would mislead users, not as an assertion that every clause
is independently enforceable. Most naming disputes in open source are settled
by pointing at a document like this one, and that is what it is for.

Nothing here is legal advice.
